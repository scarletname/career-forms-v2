Тестовое задание: сервис форм
Ориентировочное время выполнения: около 2 часов
Необходимо использовать любые AI-инструменты

Контекст
Наша компания разрабатывает карьерную платформу для студентов. Для каждой стажировки или мероприятия требуется создавать индивидуальную форму отклика.
Проблема
Менеджеры не являются техническими специалистами и вынуждены заказывать каждую новую форму у разработчиков, ожидая выполнения по несколько дней.
Студенты часто бросают заполнение форм на полпути, а причина низкой конверсии остается неизвестной.
Задача
Разработать сервис, позволяющий менеджеру самостоятельно конструировать форму отклика и публиковать её по ссылке, а студенту — переходить по ссылке и заполнять её.
Ключевой сценарий (MVP)
Менеджер собирает форму в административной панели.
Форма публикуется по уникальной ссылке.
Студент переходит по ссылке и отправляет ответы.
Менеджер просматривает полученные ответы в админке.
Всё остальное — на ваше усмотрение. Мы не ждем реализации абсолютно всех идей: выберите главное. Продуманность решения важнее количества функций.
Технические требования к сдаче
Соблюдение этих требований обязательно для проверки. Решения, которые не запускаются строго по инструкции, не оцениваются.
Репозиторий: публичный репозиторий на GitHub (необходимо прислать только ссылку).
Стек: Node.js версии 20 или новее. Фреймворки и библиотеки — любые.
Запуск: выполняется двумя командами из корня репозитория: 
npm install
npm start
Доступность: после запуска сервис должен быть доступен по адресу http://localhost:3000. Порт должен настраиваться через переменную окружения PORT.
Автономность: никаких внешних зависимостей (без API-ключей, облачных сервисов и отдельно устанавливаемых СУБД). Данные должны храниться внутри проекта (например, в SQLite или JSON-файле).
Маршрутизация: админка доступна по адресу http://localhost:3000/admin без авторизации. Публичная форма доступна по ссылке, сгенерированной в админке.
Лог работы с AI: не удалять, может потребоваться на финальным этапах собеседования.
